Safe MPC-RL Control for Hydrogen-Diesel Engines

Overview

This repository is intended to document a study of constrained control strategies for hydrogen-diesel dual-fuel engine systems, with a focus on Model Predictive Control (MPC) and Reinforcement Learning (RL).

Objectives

Explore the application of MPC to constrained engine control.

Examine how reinforcement learning may complement model-based control.

Identify relevant engine performance and emissions metrics.

Document the modeling assumptions, methodology, and evaluation process.

Scope

The project focuses on simulation-based analysis. The final scope, implementation details, and results will be documented as the work progresses.

Tools

MATLAB / Simulink

Model Predictive Control

Reinforcement Learning

Project Status

Work in progress.

The repository may include the following materials as they become available:
